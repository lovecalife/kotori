# DeckLog 取り込みの調査・実装メモ

2026-10-18 に公式ページと公開スクリプト、実応答を確認。

- [閲覧ページ](https://decklog.bushiroad.com/view/19ATNY) の `chunk-2d0af6e9.44696dbc.js` で `POST /system/app/api/view/{code}` を確認。添付設計資料の GET は `[]` を返した。
- Node.js で POST + 閲覧ページの Referer を指定すると取得成功。POSTのみ、または Content-Type のみでは `[]`。Cookie・ログインは使用していない。
- `deck_id`、`game_title_id: 11`、`title`、`list[].card_number` / `num` / `card_kind` を使う。`M` はメンバー、`L` はライブ。`sub_list` の `E` はエネルギー。`num` は正の整数として検証する。
- `19ATNY`、`1AH20Q` はどちらもメンバー48枚・ライブ12枚、エネルギー12枚。`PL!-pb1-019-N` は前者0枚、後者2枚だった（取得時点）。
- [公式利用規約](https://decklog.bushiroad.com/page/guideline/) の本文は公式画面と同じ `POST /system/app/api/page/guideline` で確認。掲載情報の著作権と無許可での複製・転用等の禁止を記載している。外部ツール向けAPIの公開仕様・利用許諾は確認できていない。本機能は非公式の取得アダプターであり、公式サポートや利用許諾を示すものではない。

## 構成と挙動

Node.js / Cloudflare Workers 共通の `server/src/decklog.mjs` を使う。ブラウザーからの直接通信はCORSの制約があるため、ローカルでは画面用サーバーの `/api/decklog/{code}`、公開画面では既存 Workers の `/decklog/{code}` を呼ぶ。Pythonや追加の実行環境は不要。

任意URLはサーバーに渡さず、半角英数字4〜10文字の公開コードだけを固定ホストに送る。取得はユーザー操作時のみ、12秒のタイムアウト・1MBの応答上限・自動再試行なし。プロセス内で成功結果を30秒キャッシュし、接続元ごとに1分20回までに制限する（Workersのインスタンス間で共有する厳密な制限ではない）。

レアリティ込みのカード番号をシートの番号に照合する。完全一致を優先し、末尾のレアリティを外した番号にも対応。パラレルなど同じシート番号に対応する行は枚数を合算する。未知カードを黙って除外したり、4枚へ切り捨てたりしない。1件でも照合できなければ置換しない。

取得したデッキ名とメンバー・ライブ枚数をプレビューし、置換ボタンで編集中のデッキ全体を交換する。既存の保存済みデッキは変更せず、新規保存の状態に戻す。検討中のカードは維持する。現在のアプリはエネルギーを扱わないため、取り込み対象外であることをUIに表示する。保存スキーマと同期プロトコルは変更しない。

## 検証

`node --test scripts/test-decklog.mjs` で入力、正規化、カード照合、HTTP異常、タイムアウト、キャッシュ・取得制限を確認。テストは外部通信を行わない。

公開画面で使うには既存の Workers の更新デプロイも必要（D1マイグレーションは不要）。古い Workers は `/decklog/` を持たないため取得できない。
